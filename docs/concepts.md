# 考え方と言葉

この道具が扱うものの整理です。画面とデータはこの言葉で出来ています。

## 1. 三つの要素: 拾い・層・対象

**（層 × 層 × …）(拾い) → 対象**

| 要素 | 内容 |
| :-- | :-- |
| **拾い** | 図面の上に、数えるものを置く一手。箱（個数もの）か線（長さもの）。**必ず粗いカテゴリが付く**（何も決めないなら根 ＝「純粋な拾い」） |
| **層** | 拾いを修飾するもの。**エリア**（多角形。箱も線も覆う）と **ルート**（線分の集まり。線をなぞって覆う）。意味は **ラベル**。層 1 枚にラベルは 1 つ（ルートは代わりに長さを持つこともある） |
| **対象** | 拾いが層に修飾された結果。部材 × ラベルの組 × 数量。計算で出るもので、保存しない |

層の種類（エリア／ルート）は形の違いで、ラベルは意味の違いです。どのラベルも、どちらの層にも付けられます。

## 2. パレット（型）

| 型 | 内容 |
| :-- | :-- |
| **部材カテゴリ** | 拾いの型。部材を葉とする木。数え方（個数／長さ）を持つ。葉は **構成**（部材の集まり）を持ってよい（例: 配線表の行「CVT 100 E14×2 (G82)」→ CVT 100 × 1・IV 14 × 2・G 82 × 1。G 82 は「電線管 あり」の層の上だけ） |
| **ラベル** | 層の型。節の木（森）。**木 1 本が直交する 1 つの観点**（部屋・階・敷設 …）で、木の中の節どうしは排他（1 つの拾いに付くのは 1 本の道だけ）。節は祖先を含意する（玄関 → 1F） |
| **規則** | 節に付く「この中では、カテゴリ は 候補 のどれか」。祖先の節の規則も効く |

パレットは節から作ってよく、木に組む（親を付ける）のは集計の都合です。
親の無い節はそのまま塗れます。木の名前だけの節は「見出し」にすると塗れなくなります。

## 3. 演算（拾い 1 つについて。長さものは通る線分ごとに）

1. **ラベルを集める** — 形を中に含むエリアのラベル ∪ 線分を覆うルートのラベル（∪ 節の祖先）
2. **葉を決める** — 粗いカテゴリ以下の葉 ∩ 当てはまる規則の候補。1 つなら決まり、2 つ以上なら人が選ぶ（候補 0 は「候補なし」として残す）
3. **構成で展開する** — 構成が無ければ、葉そのものが部材 1 つ
4. **数量** — 個数ものは 1。長さものは（長さ ＋ 余長）× 本数

## 4. 骨・線・ルート（長さもの）

- **骨** = ノードと線分。層でも拾いでもない共有の土台。**線（拾い）もルート（層）も骨の上の道**で、先に引いた方が骨を作り、後の方はなぞる
- 長さは空間に依るので、線を覆うものは線と骨を共有する。これがルートとエリアの違いのすべて
- **長さはルートが与える**（線分の集まり × 長さ（平・立））。線は線分ごとに長さを上書きできる。線分ごとの長さの決め方: 線の上書き ＞ 覆う長さルートのうち最も狭いもの ＞ 未入力（旗）
- 縦（平面図の上で点になる立ち上がり・立ち下がり）は、ノードに重ねた ▲▼ の印と、点 1 つの線分（立ルート）で表す
- **余長** は拾い（線）の側。端のノードごとに足す

## 5. 集計

集計表は、対象の集合を行と列の鍵（部材・系統・平立・ラベルの木）で並べた射影です。
木の中は排他なので、同じ木の節が 2 つ付いた対象は「重複」、どれも付かない対象は「未分類」として見えます。
