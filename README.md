# 拾いツール（試作）

電気設備の積算で、図面から数量を拾うための道具の試作です。ブラウザだけで動きます（サーバー無し・ビルド無し）。

**使ってみる**: https://itomaai.github.io/experiment-hiroi-tool/

図面の PDF は、開いたブラウザの中（IndexedDB）にだけ置かれます。外へ出るのは、図面解析のタブで「解析する」を押したときだけです（選んだページと囲んだ範囲を、利用者の鍵で Google の Gemini API へ。[docs/analysis.md](docs/analysis.md)）。

## 考え方

拾いを「図面の上に置く 2 種類のもの」で組み立てます。

| | 何か | 置き方 |
| :-- | :-- | :-- |
| **拾い** | 数えるもの。**箱**（個数もの: 器具など）と **線**（長さもの: 配線など） | 右の木で粗いカテゴリを選び、記号を囲う・配線をなぞる |
| **層** | 拾いを修飾する意味。**エリア**（部屋・ラック上 …）と **ルート**（配線の通り道。長さを与える） | 囲む・なぞると「これは何か」を選ぶ画面が出る |

層には **ラベル**（例: 1F / 玄関）が付き、ラベルには **規則**（例:「この中では、ダウンライトは GS100」）が付けられます。
拾いは、重なった層の規則で部材が絞られ、候補が 1 つになれば置くだけで決まります。
集計表は、こうして出来た「部材 × ラベル × 数量」を、行と列を選んで並べたものです。

詳しくは [docs/concepts.md](docs/concepts.md)。

## 画面

タブは 4 つです。

- **図面解析** — 図面を開いて最初に触るタブ。ページごとに「送る」（解析に使う）と「拾う」（拾いのタブに出す）の印を付け、仕様書・凡例・機器表・配線表などの読みどころを囲み、Gemini に 1 回で読ませて、ページの分類とパレット（部材の木・ラベル・規則・構成・見込み・系統）と覚え書きを下書きさせます。結果はどれも人が直せます。詳しくは [docs/analysis.md](docs/analysis.md)
- **拾い** — 左にページ（縮小画像。図面解析で「拾う」にしたページだけ）、真ん中に図面、右に「置くカテゴリ」の木と、選んだものの詳細。「参照 ▾」で、図面解析で囲んだ範囲（器具表など）を小窓に出せます
- **集計** — 集計表（行・列に 部材／系統／平立／ラベルの木 を選ぶ。CSV で書き出せる）・対象の一覧・照合（パレットの見込みと、置いた数）
- **パレット** — 型の編集
  - **部材カテゴリ**: 拾うものの木。名前をその場で書くアウトライナー（Enter で兄弟・Tab で子・Shift+Tab で戻す・Alt+↑↓ で並べ替え）。右で 数え方（個数／長さ）と 構成（1 つの拾いを部材の組に展開する。例: 幹線 1A2 → CVT 100 × 1 ＋ IV 14 × 2）
  - **層のラベル**: 層に付ける意味の木（部屋・階・敷設 …）。右で、節ごとの規則（カテゴリ → 候補）を選ぶ
  - **規則の一覧**: 規則を「節 × カテゴリ」の表で見渡す
  - **系統（配線表）**: 配線表の行（番号・起点・終点・配線）。線の名前の候補になり、引いた本数で消し込む
  - **見込み（表の個数）**: 器具表などに書いてある個数。集計の「照合」で比べる
  - **まとめて貼り付け**: 字下げした文字から木を一度に作る。器具表・配線表から写した一覧をそのまま貼れる
    ```
    照明器具 [個数]
      ダウンライト
        GS100
        G100
    ```
    層のラベルでは「玄関・風除室: GS100, G100」と書くと、その候補の規則も付きます

## 拾いの画面の道具

| 道具 | キー | |
| :-- | :-- | :-- |
| 選ぶ | V | 押して選ぶ。同じ場所をもう一度押すと 1 つ下のもの。右ボタンで「ここにあるもの」の一覧。空いた所を引くと範囲選択、Delete で消す。ノードを足すのは右クリックだけ（線分の上で「ここにノードを足す」）。ノード・箱・角を引いて動かす（ノードは線やルートの下でも掴める）。エリア・線・ルート・線分は選んでから引くと動く（線・ルートは骨ごと動くので、同じ骨を共有するものもいっしょに動く）。エリアの角・線分の途中の角を引くと形が変わる |
| 箱 | B | 引いて囲う。押すだけなら直前と同じ大きさ |
| 線 | W | 押して骨をたどる（既存のノードに吸着。線分の途中から分けるなら、線分の上で右クリックしてノードを足す）。±10° で水平・垂直に揃う（Alt で自由）。Shift で曲がり角、↑↓ で立（縦）の印、Enter で置く |
| エリア | R / P | 矩形 ／ 多角形。囲むと意味を選ぶ画面 |
| ルート | L | 線と同じ操作でなぞる。終えると意味（ラベル）と長さ（平・立）を選ぶ画面。モーダルで選んだラベルは、もう一度押すか「ラベルなし（長さだけ）」で外せる。ラベルと長さは別の層（ラベルルート・長さルート）になる。長さはあとからでも置ける（ラベルルートを選んで「＋ 同じ線分に長さルートを置く」、または線分を選んで「この線分の長さ」） |

パンは Space＋ドラッグ・中ボタン・ホイール、`0` でページ全体。Ctrl+Z / Ctrl+Y で元に戻す・やり直す。
ページ全体に掛かる層（階・工事種目）は、図面の上の「＋ ページ全体の層」から置きます。

## 保存

- 作業（パレット・層・拾い）はブラウザの localStorage に自動で残ります。PDF は IndexedDB に残ります
- 「書き出す」で作業を JSON に、「…」→「パレットを書き出す」でパレットだけを JSON にできます。パレットはほかの図面で使い回せます
- 書き出した JSON に PDF は含まれません。別のブラウザで続けるときは、JSON を読み込んでから同じ PDF を開きます（PDF の指紋で同じ図面かを見ます）
- 形式は [docs/data-format.md](docs/data-format.md)

「…」→「サンプルのパレットを読み込む」で、ある建物の電気設備図（照明器具・幹線・分岐回路）を手で起こしたパレットが入ります。図面そのものは公開していません。

## 開発

```
python3 -m http.server 8792 --bind 127.0.0.1    # 置き場の根で
open http://127.0.0.1:8792/app/index.html
```

| ファイル | 中身 |
| :-- | :-- |
| `core/model.js` | 画面を持たない部分（パレット・幾何・ストア（元に戻す・下見）・演算・集計）。node でも動く |
| `core/analysis.js` | 図面解析の画面を持たない部分（注釈・ページの欄・送るものの計画・頼む文と応答の形・応答をパレットへ）。node でも動く |
| `fixtures/palette.js` | サンプルのパレットと見本 |
| `app/index.html`・`app/app.js`・`app/style.css` | 画面（拾い・集計） |
| `app/palette.js`・`app/palette.css` | 画面（パレット） |
| `app/analyze.js`・`app/analyze.css` | 画面（図面解析）と、Gemini への送り方 |
| `tests/core.test.js`・`tests/analysis.test.js` | コアの試験（`node --test tests/core.test.js tests/analysis.test.js`） |
| `tests/ui/analyze.mjs` | 図面解析の画面の試験（白紙の PDF。Gemini には送らず、作り物の応答を返す差し替えの口で通す） |
| `tests/ui/smoke.mjs` | 画面の試験（playwright。白紙の PDF を作って通す。`npm install` のあと `node tests/ui/smoke.mjs`） |
| `tests/ui/sample.mjs` | サンプル図面での試験（PDF は公開していないので、`data/sample.pdf` が在るときだけ走る） |

PDF の描画には [pdf.js](https://mozilla.github.io/pdf.js/) 2.16 を、図面解析で PDF のページを切り出すのには [pdf-lib](https://pdf-lib.js.org/) 1.17 を、CDN から読みます。
